Deploying to Render

${avatarsm:Amara Okafor}Amara Okafor Updated 2 h ago Published deployops

The app runs on Render from the Dockerfile in the repo root. Every push to main builds a new image.

Before you deploy

  • Run the tests locally.
  • Check that SPRING_DATA_MONGODB_URI is set on the service.
./mvnw -q test
git push origin main
Free instances sleep after 15 minutes. The first request after that takes about 30 seconds.

release Unsaved changes

Steps

  1. Merge to main
  2. Watch the Render build
  3. Smoke-test login
